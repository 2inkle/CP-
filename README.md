# 리치 마작 (일본식 정통 룰)

컴퓨터(AI) 3명과 대국하는 4인 리치 마작 게임입니다. Node.js나 빌드 도구 없이 순수 HTML/CSS/JS로 만들어져 브라우저에서 바로 실행됩니다.

## 실행 방법

`index.html`을 더블클릭해서 브라우저로 열면 바로 플레이할 수 있습니다. (별도 서버 불필요)

## AI 시뮬레이터 (헤드리스, `sim.html`)

화면을 그리지 않고 특정 AI 성향을 다수 국(수백~수천 국) 자동으로 돌려 승률·화료율·평균타점·방총률·후로율 등
지표를 측정하는 도구입니다. `index.html`과 같은 서버에서 `sim.html`을 열면 됩니다. 새 페르소나를 추가하거나
기존 성향을 튜닝할 때마다 이 도구로 실제 경향을 확인하는 걸 권장합니다.

- 대상 좌석(분석하고 싶은 성향)과 상대 3자리(매 게임 무작위 배정) 선택 후 목표 국 수를 넣고 "시작"
- 진행 중 실시간으로 지표가 갱신되고, 각 국의 결과(목표/샹텐/폴드 여부)가 로그에 남습니다
- "로그+통계 다운로드" 로 실행 전체 기록을 JSON 파일로 저장할 수 있고, 브라우저 `localStorage`에도
  최근 20회 실행 결과가 자동 보관되어 나중에 다시 확인할 수 있습니다
- 드물게(수백 국에 한두 번) 특정 상황에서 진행이 멎는 경우가 있는데, 내장된 워치독이 1.5초 이상
  진행이 없으면 자동으로 감지해 재시도하고 로그에 남깁니다(근본 원인 미해결, 결과 정합성에는 영향 없음
  — 매 국 종료 시 점수 총합이 항상 보존되는지 별도로 검증됨)

## 지원하는 규칙

- 화료 형태: 표준형(4세트+1쌍), 치또이츠(7쌍), 국사무쌍
- 역: 리치/일발/멘젠쯔모/핀후/탄야오/이페이코·랸페이코/역패/산쇼쿠도우준·도우코우/잇츠우/챤타·준찬/토이토이/산안커우/산칸츠/치또이츠/혼로또우/쇼우산겐/혼이츠·친이츠/하이테이/호우테이/린샨카이호우/창깡/도라·우라도라·적도라
- 역만: 국사무쌍/스우안커우/다이산겐/츠이이소우/친로우토우/류이소우/다이·쇼우스우시이/구련보등/천화·지화
- 나가시만간(流し満貫): 이번 국에 요구패(노두/자패)만 버렸고 그 버림패가 한 번도 콜당하지 않았으면 유국 시 만관으로 정산
- 후(부) 계산 및 표준 점수 계산(만관/하네만/바이만/산바이만/역만), 쯔모/론 지불, 유국 시 텐파이 정산
- 東風戦(동풍전): 1국~4국, 딜러가 화료하거나 텐파이 유지 시 렌쨩(같은 국 반복)

## AI 판단 수준

모든 AI(페르소나 불문)는 아래 **공통 판단 레이어**를 공유합니다. "성격"은 이 판단 위에 얹는
가중치/목표 전환일 뿐, 판단 자체를 대체하지 않습니다.

- **우케이레 비교**: 동률 최소 샹텐 후보들 사이에서는 실제 대기 폭(남은 유효패 수)이 넓은 쪽을 선호합니다.
- **정교화된 안전패 판정**: 겐부츠 / 카베(4장 노출) / 리치 선언 이후 통과패 → 완전 안전, 스지 / 이치노리(인접패 3장 이상 노출) / 자패 3장 노출 → 비교적 안전, 그 외 → 위험, 3단계가 아니라 사실상 5단계로 판정합니다.
- **실전 푸시/폴드**: 위협(상대 리치·후로)이 감지되면 "내 샹텐·남은 대기패 수" vs "위험도"를 견주어, 승산이 없으면 안전패 위주로 갈아타고 아니면 계속 진행합니다.
- **후로(퐁/치) 기초전략**: 역패 트리플렛은 항상 콜. 그 외에는 샹텐이 나빠지지 않고, 멘젠이면 탄야오가 유지되는 콜만(야쿠 없는 함정 방지), 이미 오픈된 손패면 효율 위주로 콜합니다.
- **리치**: 페르소나가 특별히 다마텐 조건을 정해두지 않은 한, 텐파이가 되면 항상 선언합니다(리치는 대부분 상황에서 기대값이 양수라는 원칙).

시작화면에서 AI 3명에게 각각 다른 **조패 경향(성격)**을 지정할 수 있습니다. 경향은 `js/personas.js`에
`조건 → 행동` 규칙으로 정의되어 있어, 규칙을 추가/수정하는 것만으로 새 성격을 만들 수 있습니다.

| 페르소나 | 성격 |
|---|---|
| 표준형 | 위 공통 판단만 그대로 사용 (기본 AI) |
| 혼일색 지향 | 한 수트에 패가 몰리면 그 수트를 지키고 다른 수트를 먼저 정리. 위험할 땐 상황에 맞게 밀거나 접음 |
| 속공형 | 샹텐이 나아지면 치·퐁을 적극 사용, 리치보다 다마텐 선호. 어지간하면 계속 밀어붙임(폴드 문턱이 더 높음) |
| 수비형 | 상대 리치 시 안전패 위주로 강하게 버티고 자신은 리치 자제 |
| 서가을 | 위 공통 판단을 기본으로 갖되, 상황에 따라 목표를 갈아타는 캐릭터 AI (아래 참조) |

**서가을**은 매 턴 목표를 하나 골라 그에 맞게 버림패를 정합니다.
우선순위는 `배타오리 → 신중(큰 격차 1위) → 국사무쌍(요구패 6장+) → 치또이쯔(머리 3개+) → 탕야오/대요구(점수 불리 시) → 기본형` 입니다.

- 기본형에서는 한 수트를 통째로 끊고(절일문) 커쯔·역패 위주로 손패를 구성합니다.
- 2장 이상 버려진 역패는 절대 안전패로 보고 품고 있다가 텐파이가 되는 순간 버립니다.
- 도라는 신경쓰지 않지만 적도라는 남깁니다.
- 텐파이 타점이 만관 이하면 리치를 미루고 손패를 키우다가, 남이 리치하면 즉시 추격리치를 겁니다.
- 국사무쌍은 실제로 국사 샹텐이 표준형 샹텐보다 앞설 만큼 진짜 가까울 때만 노립니다(그렇지 않으면 기본형으로 진행).
- 오리(배타오리)는 상대가 실제로 **리치**했을 때만 발동합니다. 단순히 상대가 후로를 몇 번 한 정도로는 전면 후퇴하지 않고, 안전패를 살짝 더 챙기는 정도로만 반응합니다.
- 깡은 하지 않고 같은 패 4장을 그대로 들고 다니지만, 텐파이에서 깡해도 텐파이가 유지되면(영상개화 가능) 즉시 깡합니다.
- 상대 리치나 후로가 위협적이고 승산이 없다고 판단하면 배타오리로 전환합니다.

점수 상황에 따라 태도가 달라집니다.

| 상황 | 판정 | 행동 |
|---|---|---|
| 불리 | 4위이거나, 1등이 아니면서 18000점 미만 | 치·퐁을 적극적으로 하고, 요구패 수에 따라 탕야오 또는 대요구로 전환 |
| 보통 | 그 외 | 평소 성격(절일문·커쯔·역패). 후로는 몸통 2개 + 퐁 기회일 때만 |
| 큰 격차 1위 | 2위와 10000점 이상 차이 + 위협 감지 | **신중 모드** — 샹텐이 늘어나도 안전패를 우선해 버리고, 후로·리치·깡을 하지 않음 |

> 신중 모드는 상대 리치나 후로 위협이 있을 때만 켜지며, 승산이 거의 없으면 그대로 배타오리로 넘어갑니다.

## 간략화된 부분 (알려진 제약)

- 깡은 **안깡(暗槓)만** 지원합니다. 밍깡/가깡(상대 패로 깡)은 구현되어 있지 않습니다.
- 더블리치(첫 턴 무콜 리치)는 구분하지 않고 일반 리치로 처리됩니다.
- 역만의 "더블 역만"(13면 대기 국사, 스안커 탄키 등)은 구분 없이 단일 역만으로 계산됩니다.
- 안전패 판정에 이치노리/카베/리치 후 통과패까지 반영하지만, 정밀한 확률 계산(패산 매수 추적 등)까지는 하지 않는 근사치입니다.
- 임시 후리텐은 세분화하지 않고, 자신이 화료 가능한 패를 스스로 버리거나 론을 거절하면 해당 국 동안 계속 후리텐 상태가 됩니다.

## 파일 구조

- `index.html` - 화면 레이아웃
- `css/style.css` - 스타일
- `js/tiles.js` - 패 정의, 도라 계산
- `js/hand.js` - 화료 판정, 샹텐 계산
- `js/yaku.js` - 역 판정, 부/점수 계산
- `js/personas.js` - AI 조패 경향(규칙 엔진 + 페르소나 정의)
- `js/ai.js` - 컴퓨터 플레이어 로직 (우케이레 비교, 안전패 판정, 버림/리치/후로/깡 판단)
- `js/game.js` - 게임 진행 및 UI 렌더링
- `sim.html` / `js/sim-runner.js` - 헤드리스 AI 시뮬레이터 (지표 측정 + 로그 저장)
- `serve.ps1` - (선택) 로컬 정적 서버가 필요한 경우 사용하는 PowerShell 스크립트
- `SEOGAEUL_TUNING.md` - 서가을 AI 튜닝 기록(시뮬레이터로 찾은 버그, 수정 내역, 남은 과제)
